# Idées de nom

« Kilomètres » est un mot commun : il ne peut pas être déposé comme marque,
d'autres applications peuvent l'utiliser, et il se cherche mal sur les
magasins. Il reste bon comme **sous-titre descriptif** (« carnet de
kilométrage ») ; le nom lui-même gagne à être distinctif.

Critères : prononçable en anglais et en français, court, sans sens gênant,
libre sur les magasins, **.com et/ou .fr disponibles**, et aucune marque
connue en classes 9 (logiciels) et 42 (services logiciels).

Ce qui a été vérifié ici, le 15 octobre 2026 :
- **domaines** : par RDAP auprès des registres (Verisign pour .com, AFNIC pour
  .fr) ; « libre » = le registre ne connaît pas le nom ;
- **marques et applications** : recherche web rapide sur le nom exact. Ce
  n'est PAS une recherche de marque : voir « Avant de décider ».

Rendu sous l'icône : `tools/branding/out/mockups/noms.png`.

## Finalistes (.com ET .fr libres, rien trouvé en marque ni en application)

| **Kilotally** | tally = le décompte | bilingue, sobre |
| **Viakilo** | via (la route) + kilo, racines latines | bilingue |
| **Kilokeeper** | celui qui garde vos kilomètres | plutôt anglophone |

| **Trajetbook** | le carnet de trajets | francophone, compris des anglophones |

## À écarter
- **Trajeo, Kilovia, Kilomo** : .com et .fr déjà pris.
- **Odolog** : application de kilométrage existante.
- **Roadnote, Kilonote** : trop proches de « Driversnote », concurrent établi.
- **Kilometro / Kilomètre / Kilométrage / Mileage Log** : mots communs, non
  protégeables, déjà utilisés dans des dizaines de titres.

## Avant de décider (à faire, non fait ici)
1. Recherche de marque : INPI (data.inpi.fr), EUIPO (eSearch / TMview), OMPI
   (Global Brand Database), USPTO, classes 9 et 42, avec les graphies
   proches (Kilotrail / Kilo Trail / Kilotrael...).
2. Disponibilité du nom sur Play, App Store, Microsoft Store, AppGallery.
3. Réserver le .com et le .fr le jour même du choix (quelques euros ; un
   domaine libre aujourd'hui ne l'est pas forcément demain).
4. Dépôt à l'INPI (≈ 190 € pour une classe) ou à l'EUIPO (850 € pour une
   classe, toute l'Union) : une marque déposée est le seul moyen de faire
   retirer un clone homonyme des magasins.
