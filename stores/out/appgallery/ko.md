# Kilomètres: 주행 거리 기록

## Sous-titre / phrase courte
주행, 지출, 세금 추정

한 번의 탭으로 주행 거리 기록. 주행, 통행료, 주차비, 실제 비용 추정까지.

## Description
Kilomètres은 번거로움 없이 주행 거리를 기록합니다. 주행마다 한 번의 탭, 계정 없음, 설정할 것도 없습니다. 주행 기록은 휴대폰에 남고, 기기의 클라우드 공간에 백업되어 절대 사라지지 않습니다.

주행마다 한 번의 탭
자주 다니는 경로를 즐겨찾기로 저장하면 앱, 홈 화면 위젯, 워치에서 한 번의 탭으로 주행을 기록할 수 있습니다. 날짜, 출발지, 도착지, 거리, 왕복 또는 편도, 목적. 그게 전부입니다.

무료 버전에서 할 수 있는 것
• 한 달에 5회까지 직접 주행 기록
• 한 번의 탭으로 입력하는 즐겨찾는 경로
• 차량과 과세 마력
• 백업 파일과 클라우드 백업으로 데이터를 절대 잃지 않음

PRO에서 추가되는 것
• 무제한 주행 기록
• 공식 주행 요율표로 실제 비용을 추정하고 10% 기본 공제와 비교
• 통행료, 주차비, 연료비를 추정에 포함
• 휴대폰에 이미 기록된 주행 기록 가져오기
• 완전하고 인증된 내보내기: 깔끔한 PDF 보고서와 회계사나 세금 신고에 바로 쓸 수 있는 스프레드시트
• 백업 파일에서 복원, 여러 기기 간 동기화
• 홈 화면 위젯과 워치 앱
• 광고는 절대 없음

추정이지 보장이 아닙니다
실제 비용 추정은 참고용이며 보장되지 않습니다. 세무 조언이 아니며 공식 문서, 세무 당국 또는 전문가를 대신하지 않습니다. 신고 전에 본인에게 적용되는 규정을 확인하세요.

처음부터 프라이버시 중심
계정도 서버도 없습니다. 앱은 어디로도 아무것도 보내지 않습니다. 휴대폰 밖으로 나가는 데이터는 사용자가 직접 내보내거나 백업하거나 구매하는 것뿐입니다. 영수증은 참고 정보(날짜, 금액, 장소)로만 보관되며 사진으로 저장되지 않습니다.
